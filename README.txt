ECHO AI AVATAR — QUICK START

WHAT IT DOES
- Original virtual character named Echo, with a friendly language-partner personality.
- Animated blinking, floating, thinking/nodding and speaking mouth.
- Text conversation with topic prompts.
- Voice input using browser speech recognition (best supported in Chrome/Edge).
- Spoken replies using the browser's built-in speech synthesis.
- Responsive layout for desktop and mobile.

RUN IT
1. Unzip the project.
2. Open the echo_ai_avatar folder.
3. Double-click index.html, or open the folder in VS Code and use Live Server.
4. Allow microphone access when prompted.
5. Click the microphone and speak, or type a message and press Send.

IMPORTANT
This version works without paid APIs or an API key. Its response engine uses a small local set of conversational rules, so describe it honestly as a browser-based interactive AI-avatar prototype / conversational demo. If your instructor requires generative AI responses, the next upgrade is to connect a model API (for example, Gemini) through a small backend. Never put a private API key directly in a public HTML file.

DEMO CHECKLIST
- Type "Hello Echo" and send.
- Watch the avatar's mouth move while the spoken reply plays.
- Click a topic prompt.
- Click the microphone, allow access, and speak.
- Turn Voice replies off and send another message.
- Take a screenshot of the running app for Padlet / Canvas.
